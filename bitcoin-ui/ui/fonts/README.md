# Noto Sans SC BIP39 Subset

`NotoSansSC-BIP39.otf` is derived from Noto Sans CJK SC Regular and contains the
2,048 Simplified Chinese BIP39 characters plus printable ASCII interface glyphs.
It is imported by `app-window.slint` so Slint's software renderer can embed the
glyphs needed for dynamic Chinese word candidates on the device.

The source font is available at:

https://github.com/notofonts/noto-cjk/blob/main/Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Regular.otf
